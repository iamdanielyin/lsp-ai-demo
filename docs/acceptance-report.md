## 手工绑定流程的单客户入站隔离（保留）

- 先手动导入该客户的一条真实会话并同步，再绑定客户；昵称、号码和 `LSP-DEMO-TEST-001` 只辅助管理员在 Omni 定位，程序不以其自动授权。
- Webhook 先验签，再使用租户、客户/会话 ID 匹配范围。空范围、非测试客户、非消息事件返回 `ignored`，不持久化正文/会话/事件，不创建同步或 AI 任务。
- 已知会话缺少 user_id 的坐席回调使用已核实关联；不明客户的新会话不猜测身份。客户关联冲突拒绝。
- “暂停测试”清空范围并关闭自动回复，配置版本使待处理任务取消；已经提交的在途请求不能撤回。平台凭证变更且未显式指定新范围时清空白名单。
- 新增6项测试覆盖：100个非测试客户使用相同昵称/标记仍零写入和零任务；空范围仍校验签名；同客户重开会话和无 user_id 坐席事件；切换单客户/暂停/幂等；后台同步重新核实范围及手动导入；凭证变化清空范围。
- 100个事件测试为功能回归，不是压力测试。平台全量回调的网络/验签成本仍存在，没有全租户吞吐或“零影响”保证，部署应确认平台过滤能力和入口容量。

## 已修复并保留的回归项

1. 增量历史不能使用最新本地消息时间：Webhook 可能领先 API 拉取，必须沿用最后成功 API 同步游标，否则中间消息会漏读。
2. 新会话采用全局启用时间边界，不能以收到事件时刻重新起算，否则启用后的首条消息可能被错误归为历史。
3. 较旧乱序事件不得取消或重复生成已经针对最新客户消息的计划。
4. 坐席/API 出站回声的 `message_source` 不覆盖客户原渠道来源。
5. 轮询保留已分页载入的早期消息和展开的检查详情；脚本文本始终转义。

这些已经沉淀为项目自动化测试或本地浏览器证据；未修改全局或仓库 AGENTS.md。
